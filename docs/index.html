Built for real payload work

Useful for ServiceNow request payloads, API responses, logs, configuration values, escaped JSON, and technical text on ordinary webpages.

Format instantly

Select text, focus a field, or pick an element. FormatLens detects JSON—including escaped and nested strings—and formats it locally.

Explore precisely

Search across content and JSON paths, expand a tree, and copy one value, one path, or the complete formatted document.

Stay beside your work

The side panel keeps the source page visible. Word wrap and system, light, and dark themes make long payloads easier to inspect.

Private by design

FormatLens has no account, backend, analytics, advertising, or remote code. Webpage content is processed only in your browser and is not uploaded or stored by the extension.
